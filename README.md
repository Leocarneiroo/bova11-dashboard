Páginas geradas pelo `bova11_runner.py` do repositório principal, na branch `main`.

Esta branch contém **apenas o site**: `index.html`, as páginas dos módulos, `shared.css`/`shared.js` e o histórico recente em `arquivos/`. Cada publicação poda o conteúdo antigo — ficam as 5 sessões mais recentes de cada série e os 3 arquivos mais recentes de `arquivos/`.

O workflow `Publish dashboard` comprime `arquivos/`, valida o limite de 1 GB do GitHub Pages e faz o deploy.
